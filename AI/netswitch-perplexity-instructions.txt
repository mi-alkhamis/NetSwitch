PROJECT: NetSwitch — a native macOS menu bar utility

WHAT IT DOES
NetSwitch lets a user save named network "profiles" (DNS servers, static IP/subnet/router or DHCP) and apply them instantly from a macOS menu bar dropdown, instead of manually reconfiguring System Settings every time they move between home/office/public networks.

STACK & CONSTRAINTS (do not deviate without asking)
- Swift 5.9+, SwiftUI, native AppKit/Foundation only — no third-party dependencies, no CocoaPods/SPM external packages unless explicitly approved first
- App target uses SwiftUI's MenuBarExtra + Settings scenes (no manually-managed NSStatusItem/NSWindow)
- App Sandbox is ENABLED from day one — every new capability must go through Xcode's Signing & Capabilities, never assume unrestricted filesystem/process access
- Network changes are applied by shelling out to Apple's own /usr/sbin/networksetup CLI via Swift's Process API — do not attempt to use private/undocumented frameworks
- Elevated/admin-required operations (setting static IP, DNS, DHCP) go through `osascript -e 'do shell script "..." with administrator privileges'`, which surfaces the native macOS password prompt — this is the intended v1 privilege model, not a shortcut to replace
- Profiles persist as JSON in ~/Library/Application Support/NetSwitch/profiles.json (no CloudKit yet — that's a later phase)

CURRENT PHASE: Phase 1 — Core v0.1 loop
Goal: one profile can be created, saved, and actually applied. Scope for this phase ONLY:
